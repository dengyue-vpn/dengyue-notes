区别一：地区名单可能不同

服务 网页 / App 名单 API 名单 日本、新加坡、韩国、台湾 香港
OpenAI ChatGPT 名单（网页和手机共用） API 名单 两张都列出 两张都未列出
Anthropic Supported Regions Policy 一份政策覆盖 Claude.ai、Claude Code 和 API API 文档的 Supported regions 两页都列出 两页都未列出
Google 网页版、手机 App 各一张 Gemini API 和 AI Studio 名单 三张都列出 网页和 App 列出，API 未列出

Gemini 是个清楚的例子：同一个出口，网页版名单里有，API 名单里没有。只看网页能不能打开，推不出 API 的结论。要网页和 API 都用，出口就选几张名单都有的地区。

区别二：计费账户不同

三家都把聊天订阅和 API 分开收费：

  • OpenAI：帮助中心 9039756 写明「ChatGPT and the API platform have separate billing systems」，并且「API usage is billed separately from your ChatGPT subscription」。
  • Anthropic：帮助中心 9876003 写明「the Claude API is billed separately」。同一段说明 Max 和 Team 套餐每月含一定 API 额度。
  • Google：Gemini API 的 Billing 文档 写明「The Gemini API uses Cloud Billing accounts for billing services」，走 Google Cloud 结算账户。

也就是说，订了 ChatGPT 或 Claude 的付费订阅，不一定有 API 额度（Anthropic 的 Max、Team 例外，含部分额度），API 要另外开通、另外付费。

区别三：请求从哪台机器发出

网页聊天时，请求从你的浏览器发出，走的是你电脑或手机上开着的线路。调用 API 时，请求从运行代码的那台机器发出：

  • 代码在自己电脑上跑：和网页一样走你开着的线路，出口就是线路所在地区。
  • 代码在云服务器上跑：请求从云服务器直接发出，出口是服务器所在地区，和你电脑上开的线路无关。选云服务器时，机房地区也要在 API 名单里。

区别四：对网络的要求不同

网页聊天 API 调用
连接方式 浏览器或 App，断了可以手动刷新 程序发请求，断了要靠代码或工具自己重试
回答怎么回来 边生成边显示 可以一次返回，也可以流式返回。OpenAI 文档写明流式响应用 server-sent events
持续时间 一问一答 批量任务、长任务可能连续跑很久
出问题时的表现 页面卡住、提示网络错误 超时、半截响应、重试耗尽

所以 API 对连续性的要求通常比网页更高。长时间运行的编程助手是典型场景，见 编程助手长时间工作，网络要满足哪些条件。

一张核对清单

在打算用 API 之前，逐项回答：

  1. 你用的出口地区，在 API 名单里吗？不要拿网页版名单代替。
  2. API 账户开通了吗，付费方式加好了吗？订阅和 API 是两套账。
  3. 订阅里包不包含 API 额度？（三家目前都分开计费，Anthropic 的 Max、Team 含部分额度。）
  4. 代码在哪台机器上跑？那台机器的出口在哪个地区？
  5. 程序有没有超时和重试设置？晚高峰跑一次真实任务，记下失败次数。
