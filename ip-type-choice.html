机房 IP、住宅 IP、原生 IP 有什么区别，买之前该看哪一项

本文原载于登月VPN 博客，内容与后续更新以原文为准。

机房 IP 是数据中心服务器的地址，住宅 IP 是宽带运营商分给住户的地址。「原生 IP」没有统一的标准定义，一般指登记国家和定位国家一致。三种都是数据库的判断。

下面分三步讲：这几个词分别对应数据库里的哪一项，它们对你选服务有多大影响，以及怎么自己查。

三个词各指什么

先分清一件事：一个 IP「是什么类型」，没有一个全球统一的权威答案。你在各种查询网站上看到的「机房」「住宅」「原生」，都来自商业 IP 数据库的判断，比如 MaxMind 和 IPinfo。

说法 实际在说什么 数据库里大致对应 谁来判断
机房 IP 这个地址属于云服务、托管机房 MaxMind 的 user_type: hosting、IPinfo 的 ASN 类型 hosting 数据库厂商
住宅 IP 这个地址属于家庭宽带运营商，分给普通住户 MaxMind 的 user_type: residential、IPinfo 的 ASN 类型 isp 数据库厂商
原生 IP 登记国家和数据库判断的使用国家是同一个 MaxMind 的 registered_country 与 country 一致 没有统一定义，是行业说法

几个关键字段，官方文档是这么写的（2026-10-11 核对）：

  • MaxMind 的 country：MaxMind 认为终端用户所在的国家。registered_country：ISP 为这个 IP 登记的国家。前者是估计，后者是登记信息，两者可以不同。
  • MaxMind 的 user_type 有 hosting、residential、business、cellular 等十几种取值，文档只列了取值，没有逐项给定义。
  • IPinfo 的 ASN 接口只说 type 字段表示「拥有这个 ASN 的组织类型」，取值是 isp、hosting、business、education、government，同样没有逐项定义。

ASN 是什么：RIPE NCC 的说法是，一个自治系统是由一个或多个网络运营者管理、有统一路由策略的一组 IP 网络，每个自治系统有一个唯一编号，这个编号就是 ASN。查一个 IP 属于哪个 ASN，基本就能知道它是哪家公司在用。

「原生 IP」为什么说不清

「原生」这个词，在 RIPE、MaxMind、IPinfo 的文档里都找不到。中文圈常用它区分两种情况：

  • IP 的登记国家和服务器所在国家一致，常被叫作「原生」。
  • IP 段登记在 A 国，实际在 B 国使用，常被叫作「广播 IP」。

问题在于，「使用国家」本来就是数据库的估计。IP 地址的持有者可以按 RFC 8805 自己发布「地理位置订阅文件」（geofeed），告诉数据库厂商哪个网段在哪个国家。MaxMind 也有公开的数据更正申请页。所以同一个 IP，今天在某个数据库里显示 A 国，下个月可能变，不同数据库之间也可能不一样。

MaxMind 在自己的精度对比页上写明，它不能保证未来任何特定的准确度水平。连数据库厂商自己都不保证的东西，卖家在宣传里写「100% 原生」，你就只能当作一句说法。

这对你的购买选择有什么影响

大多数人：IP 类型排在后面，先看晚高峰稳不稳。 看网页、看视频、开会、看行情，用的是机房 IP 还是住宅 IP，体验上差别主要来自线路本身。判断线路稳不稳，参考稳定 VPN 推荐怎么看。

在意「定位国家」的人：查 country，别只听「原生」两个字。 如果某个网站按 IP 判断你在哪个国家，它用的也是某家数据库。买之前问清楚：出口在哪个国家、IP 归哪个 ASN。买之后自己查一次（方法见下一节）。

想买「住宅 IP」的人：先想清楚住宅 IP 从哪里来。 住宅 IP 本来是宽带运营商分给住户的，服务商要拿到它，只能通过和运营商合作，或者借用别人家的网络。MaxMind 专门有一个标记，叫「住宅代理」（is_residential_proxy），定义是：IP 属于住宅宽带运营商，但处在疑似匿名化的网络上。也就是说，「住宅 IP」做成了代理服务，数据库也可能识别出来。这类服务的价格、来源和条款要单独核对，不能只看「住宅」两个字。

用交易所、AI 工具的人：出口国家选对、选定后别乱换，比 IP 标签重要。 交易所按「交易所 × 你的运营商」选线，见交易所用户怎么选线路。AI 工具选该服务官方支持地区的出口，比如日本、韩国（香港不在 OpenAI、Anthropic 的支持名单里），见使用 AI 工具怎么选网络。账户和地区规则以平台为准，固定一个出口国家、少来回切换更稳。

登月VPN 线路的出口是怎么回事

登月VPN 的线路都是直连：服务器放在线路名所标的国家，不中转。线路名里不加「原生」「家宽」这类标签，按我们的命名规则，这类标签只有在核实过之后才会加上。

每条线路的出口 IP 固定，不在多个国家之间自动切换。这个 IP 由使用这条线路的多位用户共用，属于共享 IP。只要你不换线路，网站每次看到的都是同一个出口国家。

每条线路的出口国家写在线路名里，比如「韩国【电信直连】01」的出口在韩国。数据库把它判成哪个国家，你可以用下面的方法自己查。线路名里还写着这条线给哪家运营商用（电信、联通或移动直连），选和你家宽带一致的那条。全部线路见线路页。

如果你需要的是「出口 IP 固定不变」，那是另一个问题，见什么情况需要固定 IP。如果你在比较「一个人用」还是「多人共用」，见独享 IP 和共享 IP 怎么选。

自己怎么核对一个 IP

  1. 连上线路，查到当前出口 IP。 很多查询网站打开首页就会显示你的 IP。
  2. 查 ASN。 在 RIPEstat 或 IPinfo 输入 IP，看它属于哪个 ASN、哪家公司。属于云厂商、托管商的，就是机房 IP。
  3. 看两个国家字段。 在 MaxMind 的查询演示页查同一个 IP，对比「定位国家」和「登记国家」。两者一致，就是通常说的「原生」。
  4. 至少查两家数据库。 两家结论不同很常见，说明这个 IP 的标签本身就有争议。
  5. 记下日期。 数据库会更新，结论只代表查询当天。

查的时候注意两点：数据库给的是概率判断，MaxMind 文档说经纬度不精确，不应用来定位具体住址。另外，查一次只说明这一刻，过一个月可以再查一次。

哪些结论不能从 IP 标签推出来

  • 「住宅 IP」只是个标签，速度快不快、晚高峰稳不稳要另外测。
  • 「原生 IP」只是个标签，某个平台能不能用要看平台自己的判断。
  • 「机房 IP」不一定会被封。网站弹验证码、限制访问，也可能来自同一 IP 上其他人的行为，Google 的帮助页就列过这种情况，见独享 IP 和共享 IP 怎么选。
  • 查询网站显示的「风险分」「欺诈分」是各家自己的算法，没有统一标准。
