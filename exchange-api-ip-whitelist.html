交易所 API 白名单：用云服务器还是固定出口线路

本文原载于登月VPN 博客，内容与后续更新以原文为准。

手动交易、偶尔用程序拉行情或下单，用出口 IP 固定的线路设白名单就够。长期跑交易程序、要开提现权限，更适合云服务器的独立固定 IP。

区别在两点：出口 IP 是否固定，是否只有你一个人用。

先看交易所怎么规定，再比较两种做法。

各家对 API 白名单怎么规定

以下均为官方页面原文要点，2026-10-11 核对。

币安。 帮助中心《How to Create API Keys on Binance?》（页面写最后更新 2025-03-20）写明：不限制 IP 的 HMAC 密钥只有读取权限，原文是 Unrestricted-IP-Access HMAC API Key(s) won't have any permission other than reading。要开提现权限，必须添加 IPv4 白名单。密钥、IP 或权限不符时，错误码文档里对应的是 -2015，原文是 Invalid API-key, IP, or permissions for action。

欧易（OKX）。 API 文档写明：每个 API Key 最多绑定 20 个 IP，支持 IPv4、IPv6 和网段。没有绑定 IP、又有交易或提现权限的 Key，连续 14 天不用会被自动删除（API 常见问题，页面更新于 2026-09-28）。IP 不在白名单时返回错误码 50110：Your IP {param0} is not included in your API key's IP whitelist。另有 50121：You can't access our services through the IP address（不能通过该 IP 访问服务）。

Kraken。 开发者文档《API key permissions》建议：Use IP whitelisting. Lock your API key to the IP addresses your trading system runs from.（把 API Key 锁定到你交易程序运行的 IP 上。）这一页没有写 IP 不符时返回什么错误。

Hyperliquid。 它的 API 用钱包签名授权，可以另外批准「API 钱包」代为签名（文档）。我们读到的这页和限频页都没有提到 IP 白名单功能，但它的限频按 IP 计算，比如每个 IP 最多 10 个 WebSocket 连接、REST 每分钟合计权重 1200。

Bybit。 它的 API 集成文档写明，API 会按请求 IP 所在地区判断，不支持的地区返回 403 Forbidden。所以程序调 Bybit API，出口也要放在推荐地区，Bybit 推荐韩国线，见 Bybit、Bitget 提示 IP 受限怎么办。

两种做法比一比

云服务器独立固定 IP 线路服务的固定出口 IP
IP 是否固定 一般固定，换不换由你决定 看服务商，服务器故障或线路调整时可能更换
是否独享 独享 多数是多人共用，要问清
白名单的防护作用 完整：只有你的服务器能用这把 Key 打折：同一出口的其他用户和你来自同一个 IP
按 IP 计的限频 只有你自己的请求 同一出口上所有人的请求可能一起算
程序在哪跑 程序直接跑在服务器上，不经过你家网络 程序跑在你电脑上，家里断网或晚高峰拥堵，程序跟着受影响
你要自己负责的 服务器运维、安全、服务器地区选择 服务商换 IP 时及时改白名单
适合 长期、全天候跑程序 手动交易、轻量 API

云服务器的地区，和选线路一个道理：交易所按 IP 判断你从哪里来，选在推荐给这家交易所的地区。各家推荐哪些地区，见 交易所用哪条线路：10 家交易所按电信、联通、移动选线。

什么时候固定出口线路就够用

  • 只读权限的 Key，用来拉行情、看持仓，不下单、不提现。
  • 手动交易为主，偶尔用程序辅助，断开几分钟能接受。
  • 服务商明确告诉你出口 IP 固定。

即便如此，不要把带提现权限的 Key 绑到一个多人共用的 IP 上。 白名单的意义是「只有这个 IP 能用这把 Key」，IP 是共用的，这层保护就弱了很多。

什么场景真需要固定 IP，可以再看 什么情况需要固定 IP 和 独享 IP 和共享 IP 怎么选。

设白名单前的核对清单

  1. 出口 IP（线路或云服务器）在不在推荐给这家交易所的地区。
  2. 这把 Key 需要什么权限，能只给读取就只给读取。
  3. 出口 IP 是否固定、是否独享。
  4. 程序断线后能否自动重连、补齐数据，断线期间的挂单怎么处理。
  5. 不把 API Key 和密钥交给任何线路服务商，包括登月VPN。

账户和地区规则以平台为准，固定一个出口国家、少来回切换更稳：白名单绑的是 IP，出口一换，程序就会报错。
