用 ChatGPT、Claude、Gemini 选哪个出口地区：按官方支持名单选线路

本文原载于登月VPN 博客，内容与后续更新以原文为准。

用 ChatGPT、Claude、Gemini，出口地区选日本或韩国。 这两个地区同时在 OpenAI、Anthropic、Google 的官方支持名单里，登月VPN 在日本、韩国都按电信、联通、移动分别开了直连线路。

用 ChatGPT、Claude 选日本或韩国线，香港不在这两家名单里。以下名单均于 2026-10-11 核对。

按宽带直接选线路

你的宽带 推荐 也可选

挑好一条就固定用它。这几条线路的出口都在日本或韩国，ChatGPT、Claude、Gemini 用同一条即可，不用为每个 AI 单独换线。

美国也在三家名单里，但登月VPN 的美国线路是日常上网线路，不承诺 AI 用途。

两点要留意：

  • Gemini 的三张名单不一样。 香港在网页版和手机 App 名单里，不在 API 名单里。只用 Gemini 网页或 App 的话香港也行。要连 API 一起用，还是选日本或韩国。
  • Anthropic 一份政策管全部产品。 网页、Claude Code、API 都按同一份名单，选一个名单内的出口就够了。

名单会变，用之前可以点上面的链接再看一眼。

为什么这样选

  1. 出口在名单里。 线路出口在哪个国家，连接就从哪个国家发出。上表日本、韩国两个地区，三家的每张名单都列出。
  2. 按运营商直连，离得近。 日本、韩国离大陆近，登月VPN 在这两个地区按电信、联通、移动分别开了直连线路，选和你宽带对应的那条。
  3. 出口 IP 固定。 登月VPN 每条线路的出口 IP 固定，不在多个国家之间自动切换。账户和地区规则以平台为准，固定一个出口地区、少来回切换更稳。

连上以后，网络看什么

AI 的回答是边生成边显示的（OpenAI 的 API 文档写明，流式回答通过 server-sent events 传输），一整段回答期间连接都要保持住。这种用法怕的是中途断，峰值速度反而没那么要紧：

  • 看晚高峰。 晚上 8 点到 11 点是线路容易变差的时段，白天测得好，晚上不一定也好。
  • 看卡顿和丢包。 选线时可以参考的门槛，举例：晚高峰不能出现 ≥1 秒的卡顿，每 8 个包最多丢 1 个。你自己测时也可以用这把尺子。
  • 电信、联通、移动分开看。 同一个地区，不同运营商走的路由不一样，所以线路名里写明了适合哪家运营商。

长时间开着的编程助手对网络要求更高，单独写在 编程助手长时间工作，网络要满足哪些条件。
