本文原载于登月VPN 博客，内容与后续更新以原文为准。

用 Claude，选日本或韩国线路。 Anthropic 用一份支持地区名单管全部 Claude 产品，这两个地区都在列（2026-10-11 核对），网页、Claude Code 和 API 用同一条线路即可。

新加坡、台湾、美国也在名单里，香港不在。登月VPN 在日本、韩国都有按运营商分开的直连线路，下面按宽带直接给出推荐。

登月VPN 的美国线路是日常上网线路，不承诺 AI 用途。

一份名单管哪些产品

Anthropic 的 Supported Regions Policy（页面未标日期，2026-10-11 读取）开头写明，这份名单适用于：

"our apps (such as Claude.ai, Claude Code, and Cowork), our API and developer platform, and Claude models offered through cloud platforms and authorized resellers"

大意：网页和客户端（Claude.ai、Claude Code、Cowork）、API 和开发者平台，以及通过云平台和授权经销商提供的 Claude 模型。

所以不管你是在网页上聊天、用 Claude Code 写代码，还是调 API，看的都是同一份名单。日本、新加坡、韩国（South Korea）、台湾、美国都在列。API 文档里的 Supported regions 页面里，这五个地区同样在列。

订阅和 API 分开计费

Claude 帮助中心文章 9876003 写道：

"A paid Claude subscription enhances your chat experience, and the Claude API is billed separately."

大意：付费订阅改善的是聊天体验，API 单独计费。同一段还写明 Max 和 Team 套餐每月含一定的 API 额度。网页聊天和 API 调用的更多区别，见 AI 网页能用就代表 API 能用吗。

用 Claude Code，网络要求更高

Claude Code 一个任务可能跑很久。官方文档里写了默认 10 分钟的请求超时、断线重试次数，以及需要访问的一串域名。这意味着线路要撑得住长连接，晚高峰不能频繁卡顿。具体参数和自测方法写在 编程助手长时间工作，网络要满足哪些条件。

「Claude 专用」要不要加钱

用 Claude 要看的是两件事：出口地区在 Anthropic 名单里，出口固定不乱跳。一条出口在名单内、IP 固定的普通线路就满足这两点。「Claude 专用」「Claude 稳定」这类标签怎么核对，见 「AI 专用节点」值得加钱吗。
