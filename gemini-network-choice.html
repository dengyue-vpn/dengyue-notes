Gemini 网页、App、API 用哪个地区的线路：三张官方名单不一样

本文原载于登月VPN 博客，内容与后续更新以原文为准。

用 Gemini，选日本或韩国线路省心。 这两个地区在网页版、手机 App、API 三张官方名单里都在（2026-10-11 核对），一条线路三种用法通用。

香港在网页版和手机 App 名单里，不在 API 名单里。只用网页或 App 的话，香港线路也可以选。

网页版名单页写的是「over 230 countries and territories」，手机 App 页写的是「more than 150 countries」，范围本来就不同。网页版页面还专门提醒：

"The Gemini mobile app may have different availability."

大意：手机 App 的可用范围可能不同。名单会更新，用之前可以打开链接再看一眼。

账号类型和年龄

Google 的 What you need to sign in to Gemini Apps 列了三种可以登录 Gemini 的账号：

  • 个人 Google 账号
  • 带有符合条件的 Workspace 版本的工作账号，并且要年满 18 岁
  • 学校账号，需要学校管理员开启

API 这边，AI Studio 的地区页把「You do not meet the minimum age requirement (18+) to access this service」列为无法访问的原因之一，即 AI Studio 要求 18 岁以上。

API 计费方面，Gemini API 的 Billing 文档写明「The Gemini API uses Cloud Billing accounts for billing services」，和网页版的订阅分开计费。网页和 API 的更多差别见 AI 网页能用就代表 API 能用吗。

「Gemini 专用节点」要不要加钱

用 Gemini 要看的是出口地区在对应名单里、出口固定不乱跳，一条出口在名单内、IP 固定的普通线路就满足。这类宣传怎么核对，见 「AI 专用节点」值得加钱吗。
