OpenAI 的两张名单

  • ChatGPT：ChatGPT Supported Countries 页面小标题是「Supported countries & regions on web and mobile」，网页版和手机 App 共用这一份名单。日本、新加坡、韩国（South Korea）、台湾、美国都在列。页面显示「Updated: 2个月前」（2026-10-11 读取时）。
  • OpenAI API：Supported countries and territories 是另一页，单独维护。上面五个地区同样在列。

名单会更新，用之前可以打开链接再看一眼。

ChatGPT 和 API 是两套计费

OpenAI 的 Managing billing for ChatGPT and the API platform 写道：

"ChatGPT and the API platform have separate billing systems."

大意：ChatGPT 和 API 平台是两套计费系统。同一页还写明「API usage is billed separately from your ChatGPT subscription」，订阅 ChatGPT 不包含 API 用量，API 要在 API 账户里单独付费。同页也提醒，ChatGPT 订阅可以通过网页、Apple App Store 或 Google Play 付费，在多个平台同时订阅可能被分别扣费。

网页和 API 的更多区别见 AI 网页能用就代表 API 能用吗。

网络看什么

ChatGPT 对网络的要求是连续，对峰值速度要求不高：

  • 回答是流式传回来的。 OpenAI 的 流式响应文档 写明流式回答通过 server-sent events 传输。整段回答期间连接不能断，中途断了，这一轮回答通常就不完整了。
  • 晚高峰比白天重要。 白天正常、晚上 9 点后变差的线路很常见。测法见 晚高峰实测方法：连续几晚在 20:00–23:00 测，电信、联通、移动分开记录。
  • 记录比感觉可靠。 记下每晚断了几次、每次多久恢复，比「感觉还行」更好比较。

「ChatGPT 专用线路」要不要加钱

有些服务商会把节点标成「ChatGPT 专用」「AI 解锁」。用 ChatGPT 要看的就两件事：出口地区在 OpenAI 名单里，出口固定不乱跳。一条出口在名单内、IP 固定的普通线路就满足这两点，不必为标签多付钱。怎么核对这类宣传，见 「AI 专用节点」值得加钱吗。
